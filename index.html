标准工作流程

1进入模块从工作台选择分析类型
2选择文件在浏览器中确认输入数据
3提交任务调用本机 BioSeq Engine
4获取结果预览并下载结果包

运行条件

GitHub Pages 只能承载网页界面，无法在云端直接运行 BWA、samtools 或 R。进行实际分析前，需要在克隆到电脑的仓库中启动：

BioSeq_Local_Service/BioSeq_Start.bat
