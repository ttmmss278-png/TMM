安装 WGS 必需工具

当前引擎已连接时，只需补充 fastp、BWA、samtools 和 bcftools。

推荐：立即安装缺失工具

适用于当前已经能够连接 BioSeq Engine v1.3.1，但 WGS 页面提示缺少 fastp、bwa、samtools 的电脑。
Install_WGS_Tools_Immediate.bat一次性安装四个 WGS 工具
下载即时安装器 返回 WGS 页面
下载后双击运行，出现管理员权限提示时选择“是”。安装窗口会显示 Ubuntu 的实时安装进度，不会再出现 240 次网页等待。

操作步骤

1下载安装器保存到桌面或下载目录
2双击运行管理员权限选择“是”
3等待完成安装 fastp、BWA、samtools、bcftools
4返回网页Ctrl+F5 后点击“检测分析环境”
安装器使用电脑中已有的 Ubuntu WSL。首次安装工具需要联网下载 Ubuntu 软件包；以后启动 BioSeq Engine 不会重复安装。

完整离线包（备用）

完整离线包包含便携 Python 和预打包 WGS 工具，体积较大。Release 构建完成后可直接尝试下载；即时安装器更适合你当前已经有 v1.3.1 引擎的情况。
